# Sicherheitsrichtlinie / Security policy

## Unterstützte Version / Supported version

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte Zeitfokus-Version bereitgestellt. Bitte aktualisiere ältere Installationen auf die aktuelle Version. Entwicklungszweige sind nicht für den produktiven Einsatz vorgesehen.

Security fixes target the latest published Zeitfokus release. Please update older installations to the current release. Development branches are not intended for production use.

## Eine Sicherheitslücke melden / Report a vulnerability

Bitte melde mögliche Sicherheitslücken vertraulich über [GitHub: Report a vulnerability](https://github.com/WeltenbummlerKA/zeitfokus/security/advisories/new). Veröffentliche ausnutzbare Details nicht in öffentlichen Issues oder Pull Requests.

Please report potential vulnerabilities privately using [GitHub: Report a vulnerability](https://github.com/WeltenbummlerKA/zeitfokus/security/advisories/new). Do not publish exploitable details in public issues or pull requests.

Bitte gib möglichst Folgendes an / Please include where possible:

- Betroffene Version und Betriebsart / Affected version and deployment configuration
- Schritte zur Reproduktion oder ein minimales Beispiel / Reproduction steps or a minimal example
- Erwartetes und tatsächliches Verhalten / Expected and actual behavior
- Mögliche Auswirkungen / Potential impact

Übermittle keine produktiven Passwörter, Tokens, personenbezogenen Zeiteinträge oder unbereinigten Datenbankkopien. Verwende synthetische Beispieldaten und schwärze vertrauliche Angaben.

Do not submit production passwords, tokens, personal time entries or unsanitized database copies. Use synthetic sample data and redact confidential information.

Die Bewertung und Abstimmung einer Veröffentlichung erfolgen im privaten GitHub-Bericht. Eine feste Reaktionszeit oder Vergütung wird nicht zugesagt.

Assessment and coordinated disclosure take place in the private GitHub report. No fixed response time or reward is promised.
